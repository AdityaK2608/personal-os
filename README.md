# Personal OS

Personal command center + knowledge base + AI COO.

## V1

Browser-only, local-first dashboard. No local software installation is required.

- Dashboard
- Tasks
- Projects
- Knowledge Base
- Activity timeline
- AI COO foundation
- Browser persistence via localStorage

## Zero-cost principle

V1 has no paid infrastructure dependency. Data is stored in the browser for this first release.

## GitHub Pages

Enable **Settings → Pages → Deploy from a branch → main → / (root)**.

The app is a single static `index.html`, so it can be served directly by GitHub Pages.
